FITTRACK
=========
-home.html          Home Page + Summary page
-task.html          Task management list 
-habit.html         Habit overview page 
-wellness.html      Sleep tracker
-style.css          The css file for all the styling of webpage
-fit.js             Js file for the overall functioning of the project

It consists of :
- A dashboard with project overview , summary , water tracker, habit graph , daily quote generator and pomodoro timer .
- the task page consists of the task manager list where user can input , change and mark task as finished or pending .
- the habit tracker where user can add a habit and mark the complete or pending .
- A wellness tab where the user input his sleep duration and keep a track of his/her sleep .
